# icons/
#
# Place three PNG icon files here:
#
#   icon16.png   — 16×16 px   (browser toolbar)
#   icon48.png   — 48×48 px   (Extensions management page)
#   icon128.png  — 128×128 px (Chrome Web Store / Edge Add-ons listing)
#
# Any image editor works. For a quick placeholder you can convert any PNG
# to the right size with ImageMagick:
#   magick input.png -resize 16x16 icon16.png
#   magick input.png -resize 48x48 icon48.png
#   magick input.png -resize 128x128 icon128.png
#
# Until you add real icons the extension will still load; Edge/Chrome will
# show a default puzzle-piece icon in the toolbar.
